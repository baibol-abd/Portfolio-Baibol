# 💻 BAYBOL | WebStudio - Портфолио начинающего разработчика

Адаптивный одностраничный сайт-портфолио, созданный с нуля на чистом HTML и CSS. Проект сверстан по готовому макету из Figma и демонстрирует базовые навыки веб-разработки, семантической верстки и работы с современным CSS.

## 🛠 Технологии
Проект написан **без использования сторонних библиотек и фреймворков** (только чистый код):
*   **HTML5** (семантическая разметка)
*   **CSS3** (Flexbox, CSS Grid, CSS Variables)
*   **Адаптивная верстка** (Mobile / Desktop)
*   **Интерактивность** (плавные hover-эффекты, transition)

## ✨ Особенности проекта
*   Полностью адаптивный дизайн (отзывчив к экранам смартфонов, планшетов и ПК).
*   Строгая структура кода и логичное именование классов.
*   Использование CSS-переменных (`:root`) для управления цветовой палитрой.
*   Кастомная векторная иконка сайта (favicon), встроенная через SVG.
*   Секции с карточками, сетками (Grid) и гибкой раскладкой (Flexbox).
